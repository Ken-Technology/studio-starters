The checklist

10 items, in the order that matters most. We ticked what we could see from outside, so fix anything we got wrong.

Close these first

7 gaps, in the order to close them. Each one comes with a first step you can take this week.

  1. A named owner for security and the audit

    First step: Name the owner this week and put the audit on their goals, even if a security hire takes it over later.

  2. Single sign-on across the tools that hold customer data

    First step: List the tools that hold customer data and mark the ones people still log into with a password.

  3. Encryption at rest and in transit, written down

    First step: Check the backups. They are the place encryption is most often missing.

  4. Access reviews every quarter

    First step: Export the user list from your identity provider and your cloud console, and review it with each team lead once.

  5. Written policies people have read

    First step: Start with the five policies auditors ask for first and have everyone acknowledge them in your HR tool.

  6. The same onboarding steps for every new hire

    First step: Write the onboarding checklist as it happens today, then add the steps that are missing.

  7. Laptops managed centrally

    First step: Count the laptops that are not enrolled anywhere. That number is your first project.

  8. A vendor list with a risk rating

    First step: Pull the list of subscriptions from your finance tool, then mark which vendors can see customer data.

  9. An incident response plan that has been tested

    First step: Run a one hour tabletop on a leaked API key and write down what was unclear.

  10. Uptime and monitoring commitments you can show

    First step: Put a status page in front of the monitoring you already have, so the history builds from today.

Everything on this list is in place. If that holds up on a closer look, Fernhill Software is ready, and the call below is a short one.
